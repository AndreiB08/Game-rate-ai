# 🎮 GameRate AI

Aplicație web pentru descoperirea jocurilor și generarea de review-uri AI.

## 🚀 Tehnologii
- React (Vite)
- Firebase Auth
- Express.js
- OpenAI API

## 🔥 Funcționalități
- Login cu Firebase
- Listă jocuri din API
- Search jocuri
- Review generat cu AI

## ▶️ Run local

Frontend:
npm run dev

Backend:
node server.js
